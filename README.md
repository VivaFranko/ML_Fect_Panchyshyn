## Запуск

Потрібен Python 3.12. Створити окреме середовище, встановити `requirements.txt`, завантажити дані через `python download_data.py`.
Архів містить дані й навчені моделі; приховане локальне середовище `.venv` до нього не входить.

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```powershell
.venv\Scripts\python.exe project\lab01.py
.venv\Scripts\python.exe project\lab02.py
.venv\Scripts\python.exe project\lab03.py
.venv\Scripts\python.exe project\lab04.py --number 20
.venv\Scripts\python.exe project\lab05.py
```

Відкрити відповідний `.ipynb` у Jupyter і виконати Restart & Run All. У ноутбуках наведено повні реалізації та результати, а не лише виклик сторонньої моделі.
Optuna №4 зберігає випробування в SQLite та може продовжити перерваний пошук. Baseline-кеш містить seed у назві. Якщо змінюються дані, логіка обробки чи простір параметрів, старі кеші/Optuna-сховище потрібно вилучити перед новим експериментом.

Підтверджені титульні дані збережено в `profile.json`. Для повторної генерації звітів запустити `build_deliverables.py --reports-only` та `export_reports.py` (потрібен Microsoft Word і pywin32 у Windows). Збережені DOCX/PDF уже готові; для їх перегляду запуск коду не потрібен.

## Методична коректність

- №1: Ames Housing, поділ до обробки, власні BGD/SGD/mini-batch, перевірка градієнтів, діагностика залишків, додатковий Ridge.
- №2: Dry Bean, точні дублікати видалено до поділу; сервер не зберігає сирі дані клієнтів; перевірено IID, α=5/1/0,3 та E=1/5/10.
- №3: заданий Kaggle-набір має шаблонні способи створення текстів; оцінки не трактуються як універсальний доказ авторства. FastText та IDF навчаються лише на Train. Додано груповий поділ за темами.
- №4: повні 898 рядків UCI; знак `-` не плутається з `?`; усі перетворення всередині CV; виконано по 30 Optuna trials для кожного пошуку, 5 outer folds, повторну 5×3 CV та SHAP. Найкращий за nested CV випадковий ліс отримав Test macro-F1=0,9326.
- №5: однакова дозволена підмножина Fashion-MNIST, однакові початкові ваги й порядок батчів, 30 епох для кожного методу. Мертві нейрони перевірені на всій Train без Dropout. Чисельна перевірка градієнтів і відновлення NPZ пройдені.

На кожну таблицю та рисунок є посилання в тексті. Рисунки Word звірено за SHA-256 із файлами обчислень і зображеннями виконаних ноутбуків. Результати перевірок: `analysis/algorithm_checks.json`, `analysis/deliverable_checks.json`.
