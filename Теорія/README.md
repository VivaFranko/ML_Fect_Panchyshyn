# ML · Інтерактивний курс

Курс за п’ятьма практичними Панчишина Володимира, ФеІ-46С, 2026.

1. Відкрий `index.html` у браузері. Уроки, формули, тренажери й тести працюють без сервера та без інтернету.
2. Почни з трьох діагностичних питань. Далі: основа → регресія → FedAvg → тексти → дерева → нейромережа.
3. У кожному уроці передбач результат тренажера, зміни параметр, поясни наслідок, переглянь формулу та код. Відповідай на чотири питання.
4. Наприкінці пройди 12 питань, повтори помилки й поясни рішення вголос. Повтори наступного дня та через тиждень.
5. Прогрес зберігається локально. Кнопки експорту/відновлення переносять відповіді та нотатки між браузерами. Експортований JSON є файлом прогресу, не навчальним результатом.

Таймкоди й субтитри відео теж працюють без сервера. Якщо браузер обмежує localStorage для file://, запусти `START.bat` у Windows з установленим Python. Після зміни способу запуску можна відновити прогрес через його експортований файл.

Відео: `video/ML_пояснення.mp4`. Озвучення українською, 18 тематичних сцен; `video/SCRIPT.md` містить повний текст, `subtitles.vtt` — субтитри. Реченнєві субтитри мають приблизні таймінги.

## Джерела та межі

- Вихідні завдання: https://github.com/olehsinkevych/machine-learning
- Реалізація та звіти: https://github.com/VivaFranko/ML_Fect_Panchyshyn
- Усі числові оцінки читаються зі збережених `lab_01..05/results/results.json`; повторне навчання для курсу не проводиться.
- Код у навчальних блоках — скорочені схеми. Для запуску використовуй повні Python/Notebook файли проєкту.
- Графіки скопійовано з реальних результатів; підписи містять відносне джерело. У тексті уроку є посилання на кожен нумерований рисунок.
- Спрощені тренажери не відтворюють повні датасети й прямо позначені як навчальні.
- 100% на шаблонному текстовому корпусі не доводить універсальне визначення авторства. FedAvg-симуляція не гарантує криптографічної приватності. Оцінки рідкісних класів мають високу мінливість.

Навчальна структура спирається на локальний skill `learning-explainer`; відео — HyperFrames, графічний компонент animated-bar-chart; без платних сервісів генерації.
